Notes for wgpu

WGSL Cheat Sheet

WebGPU Shading Language — the shader language used with wgpu, Dawn, and browser WebGPU. Syntax reference for vertex, fragment, and compute stages.

@vertex
transforms per-vertex data → clip position
@fragment
rasterized pixels → color output
@compute
general-purpose parallel work, no fixed pipeline
01

Shader structure

core

A WGSL file mixes struct definitions, global bindings, constants, and entry points in any order.

struct VertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) uv: vec2<f32>,
};

@group(0) @binding(0) var<uniform> mvp: mat4x4<f32>;

@vertex
fn vs_main(@location(0) pos: vec3<f32>) -> VertexOutput {
    var out: VertexOutput;
    out.position = mvp * vec4<f32>(pos, 1.0);
    return out;
}

@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
    return vec4<f32>(1.0, 0.0, 0.0, 1.0);
}

05

Structs

core 
struct Particle {
    position: vec2<f32>,
    velocity: vec2<f32>,
};

Fields are comma-separated. Use @location(n), @builtin(x), @size(n), @align(n) attributes for I/O or explicit layout. A runtime-sized array<T> can only be the last field in a struct used with storage.

06

Functions

core 
fn add(a: f32, b: f32) -> f32 {
    return a + b;
}

fn noReturn() {
    // no return type = void
}

Parameters pass by value except pointers. No function overloading — two functions can't share a name.

Pointers (pass-by-reference within a function body)
fn increment(p: ptr<function, i32>) {
    *p = *p + 1;
}
// call: increment(&x);

Entry points

pipeline 
@vertex
fn vs_main(@builtin(vertex_index) idx: u32) -> @builtin(position) vec4<f32> { ... }

@fragment
fn fs_main() -> @location(0) vec4<f32> { ... }

@compute @workgroup_size(8, 8, 1)
fn cs_main(@builtin(global_invocation_id) gid: vec3<u32>) { ... }
Every @builtin(x) value — complete list

These are the built-in inputs and outputs WGSL/wgpu give you for free — no bindings needed, just declare the parameter or struct field with the right @builtin(name) attribute.

@builtin(…)TypeStageDirWhat it gives you
vertex_index u32 vertex in Index of the current vertex within the draw call (respects base vertex / first index).
instance_index u32 vertex in Index of the current instance in an instanced draw.
position vec4<f32> vertex out Required output — clip-space position fed to the rasterizer.
clip_distances array<f32, N> vertex out Per-vertex user clip distances for custom clip planes (needs the clip_distances extension).
position vec4<f32> fragment in Framebuffer-space fragment coordinate — xy in pixels, z depth, w = 1/clip-w. (Not the vertex-stage value — recomputed per fragment.)
front_facing bool fragment in True if the triangle is front-facing, based on winding order.
sample_index u32 fragment in Which MSAA sample this invocation is shading (forces per-sample shading).
sample_mask u32 fragment in Bitmask of which MSAA samples cover this fragment.
frag_depth f32 fragment out Overrides the fragment's depth instead of using the rasterizer's interpolated value.
sample_mask u32 fragment out Bitmask to narrow which samples this invocation actually writes to.
local_invocation_id vec3<u32> compute in This thread's 3D position inside its workgroup (0..workgroup_size-1 per axis).
local_invocation_index u32 compute in Flattened 1D version of local_invocation_id — handy for indexing shared arrays.
global_invocation_id vec3<u32> compute in This thread's position across the entire dispatch — workgroup_id * workgroup_size + local_invocation_id.
workgroup_id vec3<u32> compute in Which workgroup this thread belongs to, within the dispatch grid.
num_workgroups vec3<u32> compute in The x, y, z dispatch size passed to dispatchWorkgroups().
Free math, no bindings: global_invocation_id = workgroup_id * workgroup_size + local_invocation_id. If you only dispatch in 1D, global_invocation_id.x is usually all you need as your array index.
Direction matters: the same name can mean different things — position is a required output from the vertex stage, but a different input value (the rasterized screen-space coord) in the fragment stage. sample_mask likewise exists as both an input and a separate output.

Control flow

core 
if (x > 0.0) {
    // ...
} else if (x < 0.0) {
    // ...
} else {
    // ...
}

for (var i: u32 = 0u; i < 10u; i = i + 1u) { ... }

var i: u32 = 0u;
while (i < 10u) {
    i = i + 1u;
}

loop {
    // infinite loop
    if (done) { break; }
    continuing {
        // runs each iteration end, before condition re-check
    }
}

switch (x) {
    case 0: { /* ... */ }
    case 1, 2: { /* ... */ }
    default: { /* ... */ }
}

discard; // fragment shader only — kill the fragment
WGSL requires parentheses around conditions (if (x), while (x)), unlike Rust.

Vectors & swizzling

core 
var v: vec4<f32> = vec4<f32>(1.0, 2.0, 3.0, 4.0);
let xy = v.xy;         // vec2<f32>
let rgb = v.rgb;       // vec3<f32> (color aliases: r g b a)
let zyx = v.zyx;       // reordering
v.x = 5.0;             // component assignment
v = vec4<f32>(v.xyz, 1.0); // reconstruct

Component names: .xyzw or .rgba — don't mix within one swizzle.

Construction shortcuts
vec3<f32>(1.0)              // splat: (1,1,1)
vec4<f32>(v3, 1.0)          // vec3 + scalar
vec4<f32>(v2, v2b)          // vec2 + vec2

Matrices

core 
var m: mat4x4<f32> = mat4x4<f32>(
    vec4<f32>(1.0, 0.0, 0.0, 0.0),
    vec4<f32>(0.0, 1.0, 0.0, 0.0),
    vec4<f32>(0.0, 0.0, 1.0, 0.0),
    vec4<f32>(0.0, 0.0, 0.0, 1.0),
); // columns, column-major

let transformed = m * vec4<f32>(pos, 1.0);
let combined = m1 * m2;

Access column: m[0] → vec4<f32>. Access element: m[0][1].

Textures & samplers

fragment 
@group(0) @binding(0) var mySampler: sampler;
@group(0) @binding(1) var myTexture: texture_2d<f32>;
@group(0) @binding(2) var myDepthTex: texture_depth_2d;

Compute shaders & workgroups

compute 
var<workgroup> shared_data: array<f32, 256>;

@compute @workgroup_size(256)
fn cs_main(
    @builtin(local_invocation_id) local_id: vec3<u32>,
    @builtin(global_invocation_id) global_id: vec3<u32>
) {
    shared_data[local_id.x] = f32(global_id.x);
    workgroupBarrier();       // sync all threads in workgroup
    storageBarrier();         // sync storage memory ops
    // ... reduction, etc.
}

Comments & misc syntax

core 
// single-line comment
/* block comment */

enable f16;               // enable an extension
diagnostic(off, derivative_uniformity); // directive

fn foo() -> bool {
    return true;
}
  • Statements end with ; (like Rust/C).
  • Blocks use { }.
  • No semicolon after a struct/function closing brace.
  • Statically typed — no implicit casts, no null, limited pointer support across function boundaries.

Minimal full compute example

compute 
@group(0) @binding(0) var<storage, read> input: array<f32>;
@group(0) @binding(1) var<storage, read_write> output: array<f32>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) id: vec3<u32>) {
    let i = id.x;
    if (i >= arrayLength(&input)) {
        return;
    }
    output[i] = input[i] * 2.0;
}

Notes for wgpu (Rust) users

wgpu
  • WGSL loads directly via device.create_shader_module(wgpu::ShaderModuleDescriptor { source: wgpu::ShaderSource::Wgsl(...), .. }).
  • Struct layouts must match Rust-side #[repr(C)] structs and buffer layouts — bytemuck plus explicit @align/@size attributes help avoid mismatches.
  • naga (used internally by wgpu) is the WGSL compiler/validator — its error messages are usually precise about type mismatches and layout issues.
