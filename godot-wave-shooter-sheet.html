01

The architecture, in four rules

"Good architecture" in a game this size is not layers of abstraction. It is four habits that keep the node tree from turning into a web of get_parent().get_parent().

1 — Behaviour lives in components, not in actors

Health is a node. So is the hitbox, the hurtbox, the flash. The player and the enemy are both just a body with a few components bolted on, which is why they can share every damage system in this sheet without a common base class.

2 — Signals go up, calls go down

A parent may call methods on its children. A child never reaches upward — it emits a signal and lets whoever owns it decide. HealthComponent does not know what a player is; it just shouts died.

3 — Anything global goes through one bus

When something needs to be heard across the whole tree — a wave started, an enemy died, the screen should shake — it goes through the Events autoload. The HUD listens to Events, not to the player. Nothing has to find anything.

4 — Process modes are part of the design

Pausing is not an if paused: return in every script. Every node declares how it behaves when the tree is paused, once, in the inspector. Part 09 covers this properly.

the testIf you can delete the enemy scene and the project still runs, your coupling is fine. If the HUD breaks because it held a reference to an enemy, route that through Events instead.

Game — state and pause

res://autoload/game.gdautoload → Game
extends Node

enum State { MENU, PLAYING, PAUSED, GAME_OVER }

var state: State = State.MENU
var score: int = 0

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS
	Events.player_died.connect(_on_player_died)
	Events.enemy_died.connect(func(_pos): score += 100)

func start_run() -> void:
	score = 0
	state = State.PLAYING
	get_tree().paused = false
	Engine.time_scale = 1.0
	Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

func toggle_pause() -> void:
	match state:
		State.PLAYING:
			state = State.PAUSED
			get_tree().paused = true
			Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
		State.PAUSED:
			state = State.PLAYING
			get_tree().paused = false
			Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

func return_to_menu() -> void:
	state = State.MENU
	get_tree().paused = false
	Engine.time_scale = 1.0
	Input.mouse_mode = Input.MOUSE_MODE_VISIBLE

func _on_player_died() -> void:
	state = State.GAME_OVER
	Engine.time_scale = 1.0
	Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
autoloads pause tooA node whose process mode is Inherit and whose parent is the tree root behaves as Pausable. That includes every autoload. If you don't set PROCESS_MODE_ALWAYS in _ready(), your audio fades and pause-menu logic will freeze the moment you pause — which is exactly when you need them.

Audio — pooled players and bus control

One node owns every sound. Callers pass a stream and a position; they never create players, never worry about a sound cutting itself off, and never touch a bus directly.

res://autoload/audio.gdautoload → Audio
extends Node

const POOL_SIZE := 16

var _flat: Array[AudioStreamPlayer] = []
var _spatial: Array[AudioStreamPlayer3D] = []
var _music: AudioStreamPlayer

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS

	_music = AudioStreamPlayer.new()
	_music.bus = "Music"
	add_child(_music)

	for i in POOL_SIZE:
		var flat := AudioStreamPlayer.new()
		flat.bus = "SFX"
		add_child(flat)
		_flat.append(flat)

		var spatial := AudioStreamPlayer3D.new()
		spatial.bus = "SFX"
		spatial.max_distance = 45.0
		spatial.unit_size = 6.0
		add_child(spatial)
		_spatial.append(spatial)

# --- one-shots ----------------------------------------------------

func play(stream: AudioStream, pitch_jitter := 0.08, volume_db := 0.0) -> void:
	var p := _free(_flat) as AudioStreamPlayer
	if p == null or stream == null:
		return
	p.stream = stream
	p.volume_db = volume_db
	p.pitch_scale = 1.0 + randf_range(-pitch_jitter, pitch_jitter)
	p.play()

func play_at(stream: AudioStream, position: Vector3, pitch_jitter := 0.08) -> void:
	var p := _free(_spatial) as AudioStreamPlayer3D
	if p == null or stream == null:
		return
	p.global_position = position
	p.stream = stream
	p.pitch_scale = 1.0 + randf_range(-pitch_jitter, pitch_jitter)
	p.play()

func _free(pool: Array) -> Node:
	for p in pool:
		if not p.playing:
			return p
	return null   # pool exhausted this frame: drop the sound, don't stutter

# --- music --------------------------------------------------------

func play_music(stream: AudioStream, fade := 0.6) -> void:
	if _music.stream == stream and _music.playing:
		return
	var t := create_tween()
	t.tween_property(_music, "volume_db", -60.0, fade)
	t.tween_callback(func():
		_music.stream = stream
		_music.play())
	t.tween_property(_music, "volume_db", 0.0, fade)

# --- bus volume, used by the settings menu ------------------------

func set_bus_volume(bus_name: String, linear: float) -> void:
	var idx := AudioServer.get_bus_index(bus_name)
	if idx < 0:
		return
	AudioServer.set_bus_volume_db(idx, linear_to_db(clampf(linear, 0.0001, 1.0)))
	AudioServer.set_bus_mute(idx, linear < 0.001)

func get_bus_volume(bus_name: String) -> float:
	var idx := AudioServer.get_bus_index(bus_name)
	if idx < 0:
		return 1.0
	return db_to_linear(AudioServer.get_bus_volume_db(idx))
linear, not decibelsA slider that runs 0 → 1 and gets fed straight into set_bus_volume_db sounds wrong: half the slider is inaudible. linear_to_db() converts a perceptually sane 0 → 1 into the −80 → 0 dB the mixer wants. Mute explicitly at the bottom, because linear_to_db(0) is negative infinity.
03

Damage components

Four small nodes that the player, the enemies and anything you add later all share. Nothing here knows what an enemy is.

HealthComponent

res://components/health_component.gdNode
class_name HealthComponent
extends Node

signal damaged(amount: float, current: float)
signal healed(amount: float, current: float)
signal died

@export var max_health: float = 100.0
@export var invuln_time: float = 0.0   # seconds of grace after a hit

var current: float
var _invuln_until: float = 0.0

var is_alive: bool:
	get: return current > 0.0

func _ready() -> void:
	current = max_health

## Returns true if the hit actually landed, so callers can skip
## spawning blood and shake on an ignored hit.
func damage(amount: float) -> bool:
	if not is_alive:
		return false
	var now := Time.get_ticks_msec() / 1000.0
	if now < _invuln_until:
		return false
	_invuln_until = now + invuln_time

	current = maxf(current - amount, 0.0)
	damaged.emit(amount, current)
	if current == 0.0:
		died.emit()
	return true

func heal(amount: float) -> void:
	if not is_alive:
		return
	var before := current
	current = minf(current + amount, max_health)
	if current > before:
		healed.emit(current - before, current)

func fraction() -> float:
	return current / max_health

Hurtbox — the thing that gets hit

An Area3D on layer 4 with no mask of its own. It never detects; it only waits to be detected. Drag the HealthComponent into its exported slot in the inspector.

res://components/hurtbox.gdArea3D · layer 4, mask none
class_name Hurtbox
extends Area3D

@export var health: HealthComponent
@export var damage_multiplier: float = 1.0   # 2.0 on a head, 0.5 on armour

func take_hit(amount: float, at: Vector3) -> void:
	if health == null:
		return
	var final := amount * damage_multiplier
	if health.damage(final):
		Events.damage_dealt.emit(at, final)

Hitbox — the thing that does the hitting

Turned off until someone calls activate(). It remembers what it already hit so a 0.12 s swing can't damage you six physics frames in a row.

res://components/hitbox.gdArea3D · layer 5, mask 4
class_name Hitbox
extends Area3D

@export var damage: float = 18.0
@export var active_time: float = 0.12

var _already_hit: Array[Node] = []

func _ready() -> void:
	monitoring = false
	area_entered.connect(_on_area_entered)

func activate() -> void:
	_already_hit.clear()
	monitoring = true
	await get_tree().create_timer(active_time).timeout
	if is_instance_valid(self):
		monitoring = false

func _on_area_entered(area: Area3D) -> void:
	if area is Hurtbox and not _already_hit.has(area):
		_already_hit.append(area)
		(area as Hurtbox).take_hit(damage, area.global_position)
overlaps are one frame lateFlipping monitoring to true does not report bodies that are already inside the area until the next physics frame. That's fine for a swing that stays active for a tenth of a second, but if you ever need an instant one-frame hitbox, await get_tree().physics_frame first and then read get_overlapping_areas() directly.

HitFlash — the white pop on impact

Rather than swapping materials, this stacks an unshaded additive overlay on top of whatever the mesh already uses, then tweens its alpha down. Works on any mesh, any material, no shader authoring.

res://components/hit_flash.gdNode
class_name HitFlash
extends Node

@export var meshes: Array[MeshInstance3D] = []
@export var color: Color = Color(1.0, 0.94, 0.88)
@export var duration: float = 0.14

var _overlay: StandardMaterial3D
var _tween: Tween

func _ready() -> void:
	_overlay = StandardMaterial3D.new()
	_overlay.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	_overlay.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
	_overlay.blend_mode = BaseMaterial3D.BLEND_MODE_ADD
	_overlay.albedo_color = Color(color.r, color.g, color.b, 0.0)
	for m in meshes:
		m.material_overlay = _overlay

func flash(strength: float = 1.0) -> void:
	if _tween != null and _tween.is_running():
		_tween.kill()
	_overlay.albedo_color.a = strength
	_tween = create_tween()
	_tween.tween_property(_overlay, "albedo_color:a", 0.0, duration) \
		.set_trans(Tween.TRANS_EXPO).set_ease(Tween.EASE_OUT)
one material per instanceBecause the overlay is built in _ready(), every spawned enemy gets its own copy. Assign a shared material resource in the inspector instead and one enemy taking a hit will flash the entire wave.

Yaw on the body, pitch on the pivot, shake on the rig below it. Keeping those on separate nodes is what stops recoil and screen shake from fighting the mouse for control of the same rotation.

res://actors/player.gdCharacterBody3D
class_name Player
extends CharacterBody3D

@export var speed: float = 6.5
@export var acceleration: float = 14.0
@export var air_control: float = 3.0
@export var jump_velocity: float = 5.2
@export var mouse_sensitivity: float = 0.0022
@export var pitch_limit: float = deg_to_rad(88.0)

@onready var pivot: Node3D = $CameraPivot
@onready var rig: ShakeRig = $CameraPivot/ShakeRig
@onready var health: HealthComponent = $HealthComponent
@onready var hurtbox: Hurtbox = $Hurtbox

var _gravity: float = ProjectSettings.get_setting("physics/3d/default_gravity")

func _ready() -> void:
	health.damaged.connect(_on_damaged)
	health.healed.connect(_on_healed)
	health.died.connect(_on_died)
	Events.player_health_changed.emit(health.current, health.max_health)

func _unhandled_input(event: InputEvent) -> void:
	if event is InputEventMouseMotion and Input.mouse_mode == Input.MOUSE_MODE_CAPTURED:
		rotate_y(-event.relative.x * mouse_sensitivity)
		pivot.rotation.x = clampf(
			pivot.rotation.x - event.relative.y * mouse_sensitivity,
			-pitch_limit, pitch_limit)

func _physics_process(delta: float) -> void:
	if not is_on_floor():
		velocity.y -= _gravity * delta
	elif Input.is_action_just_pressed("jump"):
		velocity.y = jump_velocity

	var input := Input.get_vector("move_left", "move_right", "move_forward", "move_back")
	var direction := (transform.basis * Vector3(input.x, 0.0, input.y)).normalized()
	var target := direction * speed
	var rate := acceleration if is_on_floor() else air_control

	velocity.x = move_toward(velocity.x, target.x, rate * delta * speed)
	velocity.z = move_toward(velocity.z, target.z, rate * delta * speed)
	move_and_slide()

# --- damage feedback ----------------------------------------------

func _on_damaged(_amount: float, current: float) -> void:
	Events.player_health_changed.emit(current, health.max_health)
	Events.shake_requested.emit(0.55)
	Audio.play(preload("res://audio/sfx/player_hurt.wav"))

func _on_healed(_amount: float, current: float) -> void:
	Events.player_health_changed.emit(current, health.max_health)
	Audio.play(preload("res://audio/sfx/pickup.wav"))

func _on_died() -> void:
	Events.shake_requested.emit(1.0)
	Events.player_died.emit()
	set_physics_process(false)
the pitch clampdeg_to_rad(88) rather than 90. At exactly 90° the camera basis becomes degenerate and looking straight up can flip the view. Everyone hits this once.

Shooting

Hitscan, because it is one raycast and it feels instant. Add this to player.gd.

res://actors/player.gdappend
@export var damage: float = 34.0
@export var recoil: float = 0.04

@onready var ray: RayCast3D = $CameraPivot/ShakeRig/Camera3D/ShootRay
@onready var muzzle: Node3D = $CameraPivot/ShakeRig/Camera3D/Muzzle
@onready var cooldown: Timer = $ShootCooldown

const IMPACT_FX := preload("res://fx/impact.tscn")
const SHOT_SFX := preload("res://audio/sfx/shoot.wav")

func _process(_delta: float) -> void:
	if Input.is_action_pressed("shoot") and cooldown.is_stopped():
		_shoot()

func _shoot() -> void:
	cooldown.start()
	Audio.play(SHOT_SFX, 0.12)
	rig.kick(recoil)
	Events.shake_requested.emit(0.16)

	ray.force_raycast_update()
	if not ray.is_colliding():
		return

	var point := ray.get_collision_point()
	var normal := ray.get_collision_normal()
	var hit := ray.get_collider()

	_spawn_impact(point, normal)

	if hit is Hurtbox:
		(hit as Hurtbox).take_hit(damage, point)
		Events.hitstop_requested.emit(0.045)

func _spawn_impact(point: Vector3, normal: Vector3) -> void:
	var fx := IMPACT_FX.instantiate()
	get_tree().current_scene.add_child(fx)
	fx.global_position = point
	# look_at explodes when the direction is parallel to the up vector
	if absf(normal.dot(Vector3.UP)) < 0.99:
		fx.look_at(point + normal, Vector3.UP)
the ray must be told to see areasOn ShootRay, tick Collide With → Areas as well as Bodies, and put layers 1 and 4 in its mask. A RayCast3D ignores Area3D by default, so a hurtbox-based damage system will silently never register a single hit. Also call force_raycast_update() before reading — otherwise you get last frame's result, one frame of aim behind the mouse.

The enemy

Chase, plant, lean back, slam forward, spawn a hitbox on the exact frame of impact. The wind-up is the whole design: it is what makes the attack readable, and readable is what makes it fair.

why a Pivot nodeThe capsule leans, squashes and stretches; the collision shape and the AI must not. Rotating the body itself would tilt the collider into the floor and drag the character controller with it. Give the visuals their own node and the physics never notices the animation.

Movement and facing

res://actors/enemy.gdCharacterBody3D
class_name Enemy
extends CharacterBody3D

enum State { CHASE, WINDUP, RECOVER, DEAD }

@export var speed: float = 3.4
@export var attack_range: float = 2.3
@export var turn_speed: float = 7.0
@export var health_scale: float = 1.0   # set by the wave director

@export_group("Slam")
@export var windup_angle: float = deg_to_rad(-40.0)
@export var slam_angle: float = deg_to_rad(32.0)
@export var windup_time: float = 0.45
@export var hold_time: float = 0.08
@export var slam_time: float = 0.07
@export var recover_time: float = 0.45

@onready var pivot: Node3D = $Pivot
@onready var hitbox: Hitbox = $Pivot/AttackHitbox
@onready var slam_fx: GPUParticles3D = $Pivot/AttackHitbox/SlamFX
@onready var health: HealthComponent = $HealthComponent
@onready var hurtbox: Hurtbox = $Hurtbox
@onready var flash: HitFlash = $HitFlash

const WINDUP_SFX := preload("res://audio/sfx/enemy_windup.wav")
const SLAM_SFX := preload("res://audio/sfx/enemy_slam.wav")
const HIT_SFX := preload("res://audio/sfx/enemy_hit.wav")
const DEATH_FX := preload("res://fx/death_fx.tscn")

var _state: State = State.CHASE
var _target: Node3D
var _tween: Tween
var _gravity: float = ProjectSettings.get_setting("physics/3d/default_gravity")

func _ready() -> void:
	add_to_group("enemies")
	_target = get_tree().get_first_node_in_group("player")
	health.max_health *= health_scale
	health.current = health.max_health
	health.damaged.connect(_on_damaged)
	health.died.connect(_on_died)

func _physics_process(delta: float) -> void:
	if _state == State.DEAD or _target == null:
		return

	if not is_on_floor():
		velocity.y -= _gravity * delta

	var to_target := _target.global_position - global_position
	to_target.y = 0.0

	# Keep facing the player even mid-swing, so the slam can still track you.
	if to_target.length_squared() > 0.01:
		var want := atan2(-to_target.x, -to_target.z)
		rotation.y = lerp_angle(rotation.y, want, turn_speed * delta)

	match _state:
		State.CHASE:
			if to_target.length() <= attack_range:
				_begin_slam()
			else:
				var dir := to_target.normalized()
				velocity.x = dir.x * speed
				velocity.z = dir.z * speed
		State.WINDUP, State.RECOVER:
			velocity.x = move_toward(velocity.x, 0.0, speed * 6.0 * delta)
			velocity.z = move_toward(velocity.z, 0.0, speed * 6.0 * delta)

	move_and_slide()

The slam, as one tween

The entire attack is a single chained tween. Steps run in order; parallel() attaches a step to the one before it. Read it top to bottom and you are reading the animation.

res://actors/enemy.gdappend
func _begin_slam() -> void:
	_state = State.WINDUP
	if _tween != null:
		_tween.kill()
	Audio.play_at(WINDUP_SFX, global_position, 0.06)

	_tween = create_tween()

	# 1 — lean back and stretch tall. Slow out: the threat is legible.
	_tween.tween_property(pivot, "rotation:x", windup_angle, windup_time) \
		.set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)
	_tween.parallel().tween_property(pivot, "scale", Vector3(0.86, 1.18, 0.86), windup_time) \
		.set_trans(Tween.TRANS_CUBIC).set_ease(Tween.EASE_OUT)

	# 2 — hang at the top. This pause is the player's window to move.
	_tween.tween_interval(hold_time)

	# 3 — slam. Six times faster than the wind-up, easing IN so it accelerates.
	_tween.tween_property(pivot, "rotation:x", slam_angle, slam_time) \
		.set_trans(Tween.TRANS_QUINT).set_ease(Tween.EASE_IN)
	_tween.parallel().tween_property(pivot, "scale", Vector3(1.22, 0.8, 1.22), slam_time)

	# 4 — the frame of impact
	_tween.tween_callback(_land)

	# 5 — recover and settle back upright with a little overshoot
	_tween.tween_interval(recover_time)
	_tween.tween_property(pivot, "rotation:x", 0.0, 0.3) \
		.set_trans(Tween.TRANS_BACK).set_ease(Tween.EASE_OUT)
	_tween.parallel().tween_property(pivot, "scale", Vector3.ONE, 0.3)
	_tween.tween_callback(func(): _state = State.CHASE)

func _land() -> void:
	_state = State.RECOVER
	hitbox.activate()          # 0.12 s of live damage
	slam_fx.restart()          # burst of dust at the point of impact
	Audio.play_at(SLAM_SFX, global_position, 0.1)
	Events.shake_requested.emit(0.28)
the timing is the tell0.45 s back, 0.08 s hold, 0.07 s down. Slow-then-fast is what the eye reads as force. If you make the wind-up quick and the slam slow it will look like the enemy is politely leaning on you, no matter how much dust you spawn.

Waves

One node, no state machine. It counts enemies, waits for zero, then does it again slightly harder.

res://systems/wave_director.gdNode
class_name WaveDirector
extends Node

@export var enemy_scene: PackedScene
@export var spawn_root: Node3D          # a Node3D full of Marker3Ds
@export var base_count: int = 4
@export var count_growth: int = 2
@export var health_growth: float = 0.15
@export var spawn_interval: float = 0.35
@export var break_time: float = 4.0

var wave: int = 0

var _alive: int = 0
var _spawning: bool = false
var _running: bool = false

func _ready() -> void:
	Events.enemy_died.connect(_on_enemy_died)

func start() -> void:
	wave = 0
	_running = true
	_next_wave()

func stop() -> void:
	_running = false
	get_tree().call_group("enemies", "queue_free")

func _next_wave() -> void:
	if not _running:
		return
	wave += 1
	var count := base_count + (wave - 1) * count_growth
	_alive = count
	_spawning = true
	Events.wave_started.emit(wave, count)

	var points := spawn_root.get_children()
	points.shuffle()

	for i in count:
		if not _running:
			return
		_spawn(points[i % points.size()])
		await get_tree().create_timer(spawn_interval, false).timeout

	_spawning = false
	if _alive <= 0:          # the player cleared them faster than we spawned
		_finish_wave()

func _spawn(point: Node3D) -> void:
	var e := enemy_scene.instantiate() as Enemy
	e.health_scale = 1.0 + (wave - 1) * health_growth
	e.speed += (wave - 1) * 0.12
	get_tree().current_scene.add_child(e)
	e.global_position = point.global_position

func _on_enemy_died(_pos: Vector3) -> void:
	if not _running:
		return
	_alive -= 1
	if _alive <= 0 and not _spawning:
		_finish_wave()

func _finish_wave() -> void:
	Events.wave_cleared.emit(wave)
	await get_tree().create_timer(break_time, false).timeout
	_next_wave()
SceneTreeTimer ignores pause by defaultget_tree().create_timer(t) has process_always set to true. Leave it and your waves keep spawning while the pause menu is open, and the break between waves ticks away while the player reads the settings screen. Pass false as the second argument for anything that is gameplay timing. The only timers that should ignore pause are the ones driving the pause menu itself.

ShakeRig — shake and recoil on one node

Noise-driven rather than random, so the motion is continuous instead of jittery, and trauma is squared so light hits stay light while a death rattles the room.

res://systems/shake_rig.gdNode3D, between CameraPivot and Camera3D
class_name ShakeRig
extends Node3D

@export var max_pitch: float = deg_to_rad(3.0)
@export var max_yaw: float = deg_to_rad(3.5)
@export var max_roll: float = deg_to_rad(5.0)
@export var decay: float = 1.9        # trauma lost per second
@export var noise_speed: float = 40.0
@export var recoil_recovery: float = 14.0

var trauma: float = 0.0

var _noise := FastNoiseLite.new()
var _t: float = 0.0
var _recoil: float = 0.0

func _ready() -> void:
	_noise.noise_type = FastNoiseLite.TYPE_SIMPLEX
	_noise.frequency = 0.9
	Events.shake_requested.connect(add_trauma)

func add_trauma(amount: float) -> void:
	trauma = clampf(trauma + amount, 0.0, 1.0)

func kick(amount: float) -> void:
	_recoil += amount

func _process(delta: float) -> void:
	_t += delta * noise_speed
	trauma = maxf(trauma - decay * delta, 0.0)
	_recoil = lerpf(_recoil, 0.0, clampf(recoil_recovery * delta, 0.0, 1.0))

	var s := trauma * trauma   # squared falloff

	rotation.x = max_pitch * s * _noise.get_noise_2d(_t, 0.0) + _recoil
	rotation.y = max_yaw   * s * _noise.get_noise_2d(_t, 137.0)
	rotation.z = max_roll  * s * _noise.get_noise_2d(_t, 419.0)
trauma, not "shake for 0.3 s"Three hits landing at once add up to one bigger shake instead of three overlapping timers fighting over the same rotation. And because the rig owns the rotation completely, it can overwrite it every frame without ever conflicting with mouse look — which lives one node up.

Hit stop

Forty milliseconds of near-frozen time on a connecting shot. It costs almost nothing and it is the single most effective piece of feel in the list. Add to game.gd:

res://autoload/game.gdappend
func _ready_hitstop() -> void:
	Events.hitstop_requested.connect(hitstop)

func hitstop(duration: float) -> void:
	if Engine.time_scale < 1.0:
		return                              # already stopped, don't stack
	Engine.time_scale = 0.04
	# fourth argument: ignore time scale — or the timer freezes with the game
	await get_tree().create_timer(duration, true, false, true).timeout
	Engine.time_scale = 1.0
the timer that never firesEngine.time_scale = 0.04 also slows every SceneTreeTimer. A 0.045 s hit stop measured with a normal timer takes 1.1 real seconds to end. Pass ignore_time_scale = true. Call _ready_hitstop() from _ready(), and always reset time_scale to 1.0 on game over and on returning to the menu — a crash mid-hitstop otherwise leaves the menu running in slow motion.

Pausing and menus

Godot pauses the whole tree with one boolean. What each node does about it is declared once, in the inspector, under Node → Process → Mode. No script in this project ever checks if paused.

NodeProcess modeResult
World, Player, EnemyInheritfreezes — resolves to Pausable

Inherit is not "always on"Inherit takes the parent's mode, and the tree root resolves to Pausable. So Inherit means "pauses with the game" for anything under your scene root. The four explicit modes — Pausable, When Paused, Always, Disabled — ignore the parent entirely, which is why a When Paused menu can sit inside a Pausable UI branch and still work.

After the loop

Three things that aren't part of the game but are part of shipping one. Each is self-contained — take them in any order.

A — Key rebinding at runtime

Godot's InputMap is fully writable at runtime. A rebind button is one node that listens for the next input event, swaps it into the map by action name, and hands the new binding to the settings file. Because every script asks for actions by name, nothing else in the project changes.

res://ui/rebind_button.gdButton
extends Button

@export var action: StringName = &"move_forward"

var _listening: bool = false

func _ready() -> void:
	set_process_unhandled_input(false)   # stay quiet until asked
	pressed.connect(_listen)
	_refresh()

func _listen() -> void:
	_listening = true
	text = "press any key…"
	set_process_unhandled_input(true)

func _unhandled_input(event: InputEvent) -> void:
	if not _listening:
		return
	var usable := event is InputEventKey \
		or event is InputEventMouseButton \
		or event is InputEventJoypadButton
	if not usable or not event.is_pressed():
		return

	if event is InputEventKey and event.keycode == KEY_ESCAPE:
		_stop()
		return

	_clear_conflicts(event)
	InputMap.action_erase_events(action)
	InputMap.action_add_event(action, event)
	Settings.binds[String(action)] = var_to_str(event)
	Settings.save()

	get_viewport().set_input_as_handled()
	_stop()

## If this key already belongs to something else, take it away.
func _clear_conflicts(event: InputEvent) -> void:
	for other in InputMap.get_actions():
		if other == action or String(other).begins_with("ui_"):
			continue
		if InputMap.action_has_event(other, event):
			InputMap.action_erase_events(other)
			Settings.binds.erase(String(other))

func _stop() -> void:
	_listening = false
	set_process_unhandled_input(false)
	_refresh()

func _refresh() -> void:
	var events := InputMap.action_get_events(action)
	text = events[0].as_text() if not events.is_empty() else "unbound"
physical keys, not labelsBuild your default bindings with physical keycodes. A keycode binding for W lands on Z for a French AZERTY keyboard; a physical binding lands on the key in the same place. When a player rebinds, store the event they actually pressed and it will already be physical if their defaults were.
skip the ui_ actionsInputMap.get_actions() returns Godot's own built-ins — ui_accept, ui_cancel, and friends. Filter them out of conflict checks and out of any rebinding screen, or a player can unbind their own ability to press a button.

Build the screen as one row per action, with the label on the left and a RebindButton on the right carrying the action name in its export. Add a "reset to defaults" button that calls InputMap.load_from_project_settings() and clears Settings.binds.

B — Object pooling for effects

Every impact spawns a particle scene and every hit spawns a Label3D. At ten shots a second that is a lot of instancing and freeing, and it shows up as periodic stutter once the waves get large. A pool trades that for a fixed allocation at load.

res://systems/object_pool.gdNode
class_name ObjectPool
extends Node

@export var scene: PackedScene
@export var prefill: int = 24

var _idle: Array[Node] = []

func _ready() -> void:
	for i in prefill:
		_idle.append(_build())

func _build() -> Node:
	var n := scene.instantiate()
	n.set_meta("pool", self)
	return n

func acquire(parent: Node) -> Node:
	var n: Node = _idle.pop_back() if not _idle.is_empty() else _build()
	parent.add_child(n)
	if n.has_method("on_acquire"):
		n.on_acquire()
	return n

func release(n: Node) -> void:
	if n.get_parent() != null:
		n.get_parent().remove_child(n)
	if n.has_method("on_release"):
		n.on_release()
	_idle.append(n)

func _exit_tree() -> void:
	for n in _idle:
		n.queue_free()   # nodes outside the tree are ours to free

A pooled effect returns itself instead of freeing:

res://fx/pooled_fx.gdGPUParticles3D
extends GPUParticles3D

func _ready() -> void:
	finished.connect(_return)

func on_acquire() -> void:
	restart()          # per-spawn setup goes HERE, not in _ready

func on_release() -> void:
	emitting = false

func _return() -> void:
	var pool := get_meta("pool", null) as ObjectPool
	if pool != null:
		pool.release(self)
	else:
		queue_free()
_ready runs once, foreverA pooled node is instantiated a single time and re-used for the rest of the session. Anything you put in _ready() — resetting position, resetting health, restarting a timer — will run for the first spawn and never again. That is the bug people spend an afternoon on. Put per-spawn work in on_acquire().
where it's worth itImpacts, damage numbers, shell casings, decals, projectiles. Not enemies: a handful of spawns every few seconds is nowhere near the cost of keeping thirty capsules resident, and enemy state is much harder to reset cleanly than a particle burst.

extends Node

const PATH := "user://settings.cfg"
const BUSES := ["Master", "Music", "SFX"]

var mouse_sensitivity: float = 1.0
var binds: Dictionary = {}

func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS
	load_from_disk()

func load_from_disk() -> void:
	var cfg := ConfigFile.new()
	if cfg.load(PATH) != OK:
		return                    # first launch: the defaults above are correct

	for bus_name in BUSES:
		Audio.set_bus_volume(bus_name, cfg.get_value("audio", bus_name, 1.0))

	mouse_sensitivity = cfg.get_value("game", "mouse_sensitivity", 1.0)
	binds = cfg.get_value("input", "binds", {})
	_apply_binds()

func save() -> void:
	var cfg := ConfigFile.new()
	for bus_name in BUSES:
		cfg.set_value("audio", bus_name, Audio.get_bus_volume(bus_name))
	cfg.set_value("game", "mouse_sensitivity", mouse_sensitivity)
	cfg.set_value("input", "binds", binds)
	cfg.save(PATH)

func _apply_binds() -> void:
	for action_name in binds:
		var event := str_to_var(binds[action_name]) as InputEvent
		if event == null or not InputMap.has_action(action_name):
			continue
		InputMap.action_erase_events(action_name)
		InputMap.action_add_event(action_name, event)

Then in player.gd, multiply rather than replace, so the exported tuning value stays meaningful:

res://actors/player.gdedit
var look := mouse_sensitivity * Settings.mouse_sensitivity
rotate_y(-event.relative.x * look)
autoload order is load orderSettings._ready() calls Audio.set_bus_volume(). If Settings sits above Audio in the autoload list it runs first, against an Audio node that hasn't built its pool yet. Drag it to the bottom. The list order in Project Settings is the initialisation order.
where the file goesuser:// resolves to %APPDATA%\Godot\app_userdata\<project> on Windows and ~/.local/share/godot/app_userdata/<project> on Linux. Print OS.get_user_data_dir() once and bookmark it — deleting that file is how you test the first-launch path.

Call Settings.save() when the settings screen closes, not on every slider frame. Writing a file sixty times a second while someone drags a volume slider is a real thing people ship.
